# 基于 SpringBoot+Vue 的法考智能化训练系统的设计与实现

> 本文围绕基于遗忘曲线理论的法考训练系统，结合 Java、SpringBoot、Vue 和 MySQL 技术，实现面向管理员和学生的智能化刷题、模拟考试与错题推荐功能。

## 一、项目背景

- 法考备考过程中，学生面临海量题目难以高效复习，传统刷题方式缺乏个性化推荐和科学复习节奏。
- 现有训练系统大多缺少基于遗忘曲线的错题推荐机制，主观题判分依赖人工，效率低且反馈慢。
- 管理员难以根据试题难度智能组卷，无法精准掌握学生整体学习数据。
- 本系统通过 AI 组卷、AI 主观题评分以及遗忘曲线建模，解决上述痛点，提升法考备考效率与科学性。

## 二、功能模块介绍

系统分为管理员端（网页）和学生端（网页），角色与所属端如下：

| 端       | 角色   | 说明               |
|----------|--------|--------------------|
| 网页端   | 管理员 | 管理学生、课程、题库、试卷及数据统计 |
| 网页端   | 学生   | 刷题训练、模拟考试、错题复习与统计 |

## 五、主要业务流程

1. 管理员登录系统，创建课程并在题库中添加单选、多选、主观题，设置难度星级。
2. 管理员使用 AI 智能组卷功能，根据难度要求从题库中筛选题目生成模拟试卷。
3. 学生注册登录后，选择课程进入刷题训练，可选择顺序、随机或按题型练习，主观题提交后由 AI 自动评分。
4. 学生进入模拟考试模块，选择试卷进行作答，考试结束后系统自动计算客观题得分与 AI 评分的主观题得分，汇总总分。
5. 刷题或考试中答错的题目自动进入错题库，学生可在错题库查看详情。
6. 学生选择课程进入错题重刷，系统根据遗忘曲线模型和记忆衰减周期计算推荐错题列表。
7. 学生可以在计划周期模块创建个人复习计划，设定天数与每日复习内容，系统按推荐算法安排错题复习。
8. 管理员和学生分别通过数据统计看板查看题目数量、课程数量、学生数量、模拟考试次数、学科错题统计、每日刷题趋势、课程正确率等数据。

## 六、项目拓展性

- 支持加入更多题型，如判断题、案例分析题，扩展 AI 评分模型。
- 未来可接入移动端（微信小程序或 App），实现随时随地刷题与考试。
- 错题推荐算法可结合更多维度（如学生掌握度、近期表现）进行优化。
- 可增加教师或助教角色，辅助管理员管理学生与试卷。
- 可集成在线学习社区功能，支持学生间讨论与答疑。
